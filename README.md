# LIDATO QUEST · Sala de mando

Plataforma interna gamificada de Lidato para gestionar clientes, entregas, tareas y soporte.

- Versión: v11 (octubre 2026)
- Archivo único: `index.html` (todo el código y los recursos van embebidos)
- Publicación: GitHub Pages (rama `main`, carpeta raíz)

## Datos
Los datos se guardan en el navegador (localStorage), por dominio. Al abrir la app
en una dirección nueva, usa **Exportar** en la versión anterior e **Importar** aquí
para traer tu información.

## Actualizar
Reemplaza `index.html` por la nueva versión y haz commit en `main`; Pages se
actualiza solo en uno o dos minutos.
